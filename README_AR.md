# برنامج تسيير الأجور - الجزائر (نسخة أولية)

تطبيق مستقل لنظام Windows، بواجهة عربية/إنجليزية/فرنسية، ويستخدم SQLite لحفظ البيانات محلياً. لا يحتاج Excel عند تشغيله.

## الوظائف الحالية
- إدارة العمال وإضافة بياناتهم وتعديلها وتعطيل العامل.
- تسجيل الحضور اليومي: حضور 1، غياب 0، نصف يوم 0.5، ربع يوم 0.25.
- إدخال المنح والتسبيقات والاقتطاعات.
- حساب أولي للأجر الخام والصافي وبعض المساهمات والاقتطاعات.
- تصدير CSV ونسخ احتياطي لقاعدة البيانات.

## إنشاء ملف التثبيت
راجع `INSTALL_AR.md` للحصول على خطوات مفصلة لإنشاء `AlgeriaPayroll_Setup.exe` عبر GitHub Actions، ثم تثبيته على Windows.

للبناء مباشرة على Windows، ثبّت Python 3.11 x64 وInno Setup 6 ثم شغّل `build_windows.bat`.

## حفظ البيانات
قاعدة البيانات في `%APPDATA%\AlgeriaPayroll\payroll.db`. أنشئ نسخاً احتياطية بانتظام ولا تحذف الملف.

## تنبيه قانوني ومحاسبي
هذه نسخة أولية للتجربة. لم تتم المصادقة على صيغ CNAS وIRG أو جميع حالات الأجور وفق التشريع الجزائري. لا تعتمد نتائجها للصرف أو التصريح الرسمي قبل مراجعتها وتأكيدها من مختص أجور/محاسب جزائري. اختبر الحسابات ببيانات تجريبية أولاً.


**شعار المؤسسة:** تمت إضافة شعار «الغريان للتجارة» إلى الشريط العلوي للبرنامج، ويُضمَّن تلقائياً داخل ملف EXE عند البناء.
